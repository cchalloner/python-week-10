# Week 10 Lab: Input Validation, Safe Division, File Reading, and Fixing Bugs

## Setup
1. Open this folder in VS Code (do not open just the notebook).
2. Open `week10_lab.ipynb` and select the Python kernel if prompted.
3. Complete each task directly in the notebook. For Task 3, create `data.txt` in this folder as described there.

The full instructions for each task are in the notebook. Grading details are posted in Blackboard.

## Submitting Your Work
1. Run all cells and save your notebook so your output is saved.
2. Stage, commit, and sync your changes to GitHub with a message such as: `feat: Complete Week 10 lab`. Make sure `data.txt` is included.
3. Copy your repository URL and paste it into the Week 10 Lab assignment in Blackboard.
